# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-08-07

### Added
- English desktop UI for dynamic 8x8 RNBMF S-box generation.
- Validation of 64 cyclic matrices over GF(2).
- Compatible and extended CSV export.
- Nonlinearity, LAT/LAP, SAC, differential uniformity, cycle-structure, algebraic-degree, and BCT/boomerang-uniformity analysis.
- 16x16 hexadecimal S-box inspector and 8x8 matrix views.
- Automated compatibility tests.
- GitHub Actions test workflow.
