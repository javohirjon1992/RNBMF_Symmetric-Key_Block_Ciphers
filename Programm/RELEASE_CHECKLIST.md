# Release Checklist

- [ ] Run all unit tests.
- [ ] Verify the compatible CSV against a known legacy sample.
- [ ] Update `VERSION` and `CHANGELOG.md`.
- [ ] Replace placeholders in `CITATION.cff.template` and rename it to `CITATION.cff`.
- [ ] Select and add an explicit software license before public reuse is intended.
- [ ] Create a GitHub release tag such as `v1.0.0`.
- [ ] Archive the GitHub release in a DOI-assigning repository such as Zenodo.
- [ ] Add the resulting DOI to `CITATION.cff` and the manuscript Code Availability statement.
